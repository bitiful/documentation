<Note>

为保护资源被滥用，CDN 配置 Referer 和 IP 的黑白名单来判断是否是合法用户及来源。然后 Referer 可被 **轻松伪造**，实际使用中仍存在隐患。

为了更好地保护源站资源，CDN 支持加密 URL 的功能，可以通过 **高级鉴权** 的方式来正确响应合法请求、拒绝非法请求。

</Note>

## 工作原理
在控制台为需要保护的 “加速项目” 启用“高级鉴权”，并设置一个名为 `鉴权 Key` 的“暗号”，利用与 CDN 同样策略的方式向合法用户提供利加密的 URL，并通过 ts 参数设定该 URL 的有效时间戳；

用户在访问资源时会根据下面的 `规则` 判断请求的合法性：
<Steps>
<Step title="是否有签名">
    - **是** - `继续判断下一条规则`
    - **否** - `返回 403 Forbidden`；
</Step>
<Step title="当前是否早于 _ts 参数规定的时间戳">
    - **是** - `继续判断下一条规则`
    - **否** - `返回 403 Forbidden`；
</Step>
<Step title="判断 _btf_tk 是否合法（防止 _ts 被伪造）">
    - **是** - `200 并返回资源`
    - **否** - `返回 403 Forbidden`。
</Step>
</Steps>


## 典型范例

一个正确的典型高级防盗链 URL（带有额外参数 `fmt=info`）应该类似于：

> [http://tests3origin.dogecast.com/image.jpg?`_btf_tk`=d843dd7aa694772a35389d8df73fdeb1&`_ts`=1701091625&`fmt`=info](http://tests3origin.dogecast.com/image.jpg?_btf_tk=d843dd7aa694772a35389d8df73fdeb1&_ts=1701091625&fmt=info)

其中：
- ts: 为 UTC 时间戳，意为：该 URL 的时效时间（**晚于该时间** 后链接将返回 403）
- token: 用 **tokenKey** + **path** (本例为 /image.jpg) + **?** + **args** (本例为 \_ts=1701091625fmt=info) 计算 MD5

<Tip>
  签名规则说明

  - **args** 由 `_ts=时间戳` 开头，后面依次拼接其余参数（`_btf_tk` 本身不参与），参数之间 **不加** `&`；
  - URL 中的参数顺序须与签名时的顺序一致，参数之间正常使用 `&` 连接；
  - 参数值如含特殊字符（如 `;`、`"`、空格、中文），须先 URL 编码，且签名与 URL 中使用 **同一种** 编码结果；
  - 不带额外参数时，token 仍为 **tokenKey** + **path** + **ts 的值**（如 `testsecretkey/image.jpg1701091625`）。
</Tip>
