## 自动增强

| 参数 | 含义 | 取值 |
| :-- | --- | --- |
| `enhance` | **自动画质增强**，值为强度。只写 `enhance` 不带值时为 50 | 0 ~ 100 |
| `redeye` | **去红眼** | `1` |

`enhance` 会分析画面后自动调整：校正黑白场，提亮偏暗的中间调，适度增加对比与自然饱和度。它会按画面明暗自适应：光线充足的照片改动很小，偏暗的照片改善更明显；高光区域受到保护，不会过曝。

[https://demo.bitiful.com/girl.jpeg?enhance=70](https://demo.bitiful.com/girl.jpeg?enhance=70)

也可使用 `auto` 写法组合多项：`auto=enhance,redeye`。其中 `auto=enhance` 等同于 `enhance=100`。

## 手动调色

| 参数 | 含义 | 取值 | 说明 |
| :-- | --- | :-: | --- |
| `bri` | **亮度** | -100 ~ 100 | 整体变亮或变暗 |
| `con` | **对比度** | -100 ~ 100 | -100 为全灰 |
| `gam` | **伽马** | -100 ~ 100 | 正值提亮中间调，高光与暗部基本不变 |
| `exp` | **曝光** | -100 ~ 100 | 对应正负 2 档曝光 |
| `high` | **高光** | -100 ~ 0 | 压暗高光，找回过亮区域的细节 |
| `shad` | **阴影** | -100 ~ 100 | 正值提亮暗部，负值压暗 |
| `sat` | **饱和度** | -100 ~ 100 | -100 为黑白 |
| `vib` | **自然饱和度** | -100 ~ 100 | 优先提升不饱和的颜色，保护肤色 |
| `hue` | **色相** | -360 ~ 360 | 旋转角度 |
| `sepia` | **怀旧棕褐色调** | 0 ~ 100 | 值为强度 |
| `monochrome` | **单色调** | 十六进制颜色 | 4 位或 8 位写法的首段为强度 |
| `invert` | **反相** | `1` | – |

所有参数默认为 0，即不调整。多个参数可以同时使用。

[https://demo.bitiful.com/girl.jpeg?exp=20&shad=30&vib=25](https://demo.bitiful.com/girl.jpeg?exp=20&amp;shad=30&amp;vib=25)

锐化与马赛克分别见 [图像锐化](/sharpen) 和 [图像模糊](/blur)。

## 使用说明

- **执行顺序**：自动增强在前，手动调色在后，即手动参数是在增强结果上微调。
- **宽色域**：Display P3、Adobe RGB 等宽色域图片按其原有色彩空间计算，色彩不会被压缩到 sRGB。
- **透明图片**：透明度保持不变。
- **动图**：支持，各帧使用同一组调整，不会出现帧间色调跳变。
- **HDR 图片**：调色只作用于 SDR 画面，HDR 高光信息保留。黑白、棕褐、单色调会同步去除 HDR 部分的色彩；`invert` 输出为 SDR。
- **视频**：不支持，输出视频时带这些参数会返回错误。
