**CoreIX** 是缤纷云自研的高性能实时**媒体处理引擎**。

S4 对象存储中的图片、视频等媒体内容，只需在 URL 末尾（或在 GetObject 接口中）携带**处理参数**，即可实时获得处理结果。所有处理均不会修改存储桶中的原文件。

<Warning>
  **注意** 当前处于测试阶段，暂不收费。收费时间及标准会另行通知，请您及时关注相应公告。
</Warning>

## 快速上手

在媒体文件的 URL 后加上参数即可：

```text
原图：https://demo.bitiful.com/girl.jpeg
```

加上处理参数后：[**`https://demo.bitiful.com/girl.jpeg?w=800&h=500&pos=top`**](https://demo.bitiful.com/girl.jpeg?w=800&h=500&pos=top)

![缩放并保留上部](https://demo.bitiful.com/girl.jpeg?w=800&amp;h=500&amp;pos=top)

多个参数可以自由组合，如同时缩放、加水印并转换格式。

## 核心特点

1. **超高性能**：性能最多可达国内主流图片处理服务的 **10 倍**以上；
2. **全流程 HDR**：HDR 照片与视频在裁剪、缩放、水印后仍是 HDR，也可一键映射为 SDR；
3. **专业色彩管理**：准确处理 CMYK、Display P3、Adobe RGB 等色彩空间；
4. **超大图处理**：支持高达 **200 MB** 的图片；
5. **画面感知**：裁剪时自动识别人脸、人体、宠物与主体并予以保留；可自动打码人脸、挑选视频封面；
6. **格式覆盖广**：原生支持相机 RAW、SVG、PDF、OpenEXR、JPEG XL 等格式，详见 [支持格式](/coreix/features/formats)；
7. **实况照片**：支持 iOS 与主流安卓厂商实况照片的静图、视频提取与互相转换；
8. **视频与动图**：视频截帧、剪辑，视频与动图互转；
9. **内置图片分析**：文字识别（OCR）、调色板、感知哈希、内容标签、相似图特征，以及 BlurHash、ThumbHash 占位符；
10. **量化压缩**：`fmt=tpng` 可获得类似 TinyPNG 的压缩效果。

## 自动优化

在执行你指定的参数之前，CoreIX 会先做必要的自动优化，在**画面准确**与**节省流量**之间取得平衡：

- **自动转正**：依据 Exif 方向信息自动旋转图片，支持 JPEG、PNG、WebP、AVIF、HEIF 与主流相机 RAW；
- **精简元数据**：去除分享场景中无用的 Exif 信息，最多可节省约 `500 KiB`；
- **自动色彩管理**：生成缩略图时自动完成必要的色彩空间转换并精简色彩配置文件，对特殊色彩空间的图片最多可节省约 `2.5 MiB`；
- **保留 HDR**：HDR 源默认输出 HDR；加上 `hdr-rate=0` 即映射为 SDR，不会出现灰图；
- **格式协商**：`fmt=auto` 按浏览器支持情况自动选择 JPEG XL、AVIF 或 WebP；显式指定的格式不被浏览器支持时自动降级；
- **智能无损**：图标、截图等低色数图片自动采用无损调色板编码，体积更小且不失真。

## 功能总览

### 尺寸与裁剪

| 功能 | 主要参数 | 说明 | 适用 |
| :-- | --- | --- | :-: |
| [图片缩放](/coreix/features/resize) | `w` `h` `dpr` `mode` | 等比缩放、裁切、补边、拉伸 | 全部 |
| [智能裁切](/coreix/features/resize) | `pos` | 裁切时保留指定方位，或自动保留人脸与主体 | 全部 |
| [自定义裁剪](/coreix/features/crop) | `rect` | 按坐标提取任意矩形区域 | 图片 |
| [修剪边框](/coreix/features/trim) | `trim` | 自动去除四周的纯色或透明边框 | 静图 |
| [画布与外形](/coreix/features/canvas) | `flip` `border` `pad` `box` `mask` | 翻转、边框、内边距、色块、圆角与圆形 | 图片 |

### 画质与色彩

| 功能 | 主要参数 | 说明 | 适用 |
| :-- | --- | --- | :-: |
| [质量变换](/coreix/features/quality) | `q` | 调整有损格式的压缩质量 | 全部 |
| [图像锐化](/coreix/features/sharp) | `sharp` `usm` | 提高清晰度 | 静图 |
| [图像模糊](/coreix/features/blur) | `blur` `px` | 模糊与马赛克 | 静图 |
| [调色与自动增强](/coreix/features/adjust) | `enhance` `bri` `con` `sat` 等 | 一键增强画质，或手动调整亮度、对比度、饱和度等 | 图片 |
| [色彩管理](/coreix/features/colorspace) | `cs` | 指定输出的色彩空间 | 静图 |
| [HDR 处理](/coreix/hdr) | `hdr-rate` `hdr-fmt` | 控制 HDR 亮度与输出形态，或转为 SDR | 图片、视频 |

| [水印字体](/coreix/features/watermark-fonts) | `txt-font` | 可用字体清单 | – |

| 功能 | 主要参数 | 说明 | 适用 |
| :-- | --- | --- | :-: |
| [视频和动图截帧](/coreix/features/frame) | `frame` | 按时间点或帧序号取一帧，或自动挑选封面帧 | 视频、动图 |
