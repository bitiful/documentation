本页的字体名同时适用于两处：

- 文字水印的 `txt-font` 参数；
- SVG 水印与 SVG 源图里的 `font-family`（属性、`style`、`<style>` 块均可）。

## 写法规则

- 字体名**不区分大小写**，空格、`-`、`_` 可省略：`Noto Sans SC`、`noto-sans-sc`、`NotoSansSC` 等价。
- 多个字体用半角逗号分隔，按顺序匹配：`txt-font=SmileySans,NotoSansSC`。
- 部分字体可直接写**中文名**（见下表「中文名」列），在 URL 中需 UrlEncode。
- 指定的字体缺少某个字时，系统逐字回退到对应文种的 Noto 字体，不会出现方块或乱码。
- 默认字体为 `NotoSansSC`（思源黑体）。

## 字体组

写组名时，系统按 `txt-lang` 或文字内容自动选用对应地区的版本（含假名用日文版，含谚文用韩文版，其余用简体版）。组内没有的地区使用简体版。

| 组名 | 中文名 | 简体 | 繁体 | 日文 | 韩文 | 字重 |
| :-- | --- | :-: | :-: | :-: | :-: | --- |
| `Noto` | 思源黑体 | ✓ | ✓（台 / 港） | ✓ | ✓ | 100 ~ 900 |
| `MiSans` | 小米 | ✓ | ✓ | – | – | 150 ~ 700 |
| `OPPOSans` | – | ✓ | ✓ | – | – | 100 ~ 700 |
| `HarmonyOSSans` | 鸿蒙 | ✓ | ✓ | – | – | 100 ~ 900 |
| `LINESeed` | – | – | ✓ | ✓ | ✓ | 400 / 700 / 800 |

- 需要固定某个地区版本时，写具体名字：`NotoSansTC`、`NotoSansHK`、`NotoSansJP`、`NotoSansKR`、`MiSansTC`、`OPPOSansTC`、`HarmonyOSSansTC`、`LINESeedTW`、`LINESeedJP`、`LINESeedKR`。
- `LINESeed` 没有简体中文版，简体汉字回退到思源黑体。
- `MiSans` 另含阿拉伯文、泰文、天城文、古吉拉特文、古木基文、藏文、高棉文、老挝文、缅甸文；`HarmonyOSSans` 另含阿拉伯文；`LINESeed` 另含泰文（`LINESeedTH`）。

## 其他文种

以下文种均有对应的 Noto 字体，通常无需指定，缺字时会自动回退；需要显式指定时写 `NotoSans` 加文种名，如 `NotoSansArabic`。

| 文种 | 字体名 |
| --- | --- |
| 拉丁 / 希腊 / 西里尔 / 越南文 | `NotoSans` |
| 阿拉伯文、希伯来文 | `NotoSansArabic`、`NotoSansHebrew` |
| 泰文、老挝文、高棉文、缅甸文 | `NotoSansThai`、`NotoSansLao`、`NotoSansKhmer`、`NotoSansMyanmar` |
| 天城文、孟加拉文、泰米尔文、泰卢固文 | `NotoSansDevanagari`、`NotoSansBengali`、`NotoSansTamil`、`NotoSansTelugu` |
| 卡纳达文、马拉雅拉姆文、古吉拉特文、古木基文、僧伽罗文 | `NotoSansKannada`、`NotoSansMalayalam`、`NotoSansGujarati`、`NotoSansGurmukhi`、`NotoSansSinhala` |
| 格鲁吉亚文、亚美尼亚文、埃塞俄比亚文、蒙古文 | `NotoSansGeorgian`、`NotoSansArmenian`、`NotoSansEthiopic`、`NotoSansMongolian` |
| 藏文 | `NotoSerifTibetan` |

<Tip>
  字重（`txt-weight`）只在字体提供该字重时生效。单字重字体无论传什么值，显示效果都相同。
</Tip>

## 字体授权声明

本服务的文字水印与 SVG 渲染使用了以下字体：阿里巴巴普惠体、OPPO Sans、HarmonyOS Sans、MiSans、LINE Seed，以及 Noto、思源、霞鹜文楷、得意黑、抖音美好体、站酷系列等开源字体。
